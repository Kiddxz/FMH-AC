# Extra 54: nearest coming appointment on top

- Clinic appointment list (Staff, Vet/Admin): tabs Upcoming (default) / Past / All.
  - Upcoming: today and later, the nearest date and time first (e.g. tomorrow 9:00 AM before tomorrow 2:00 PM).
  - Past: earlier appointments, the latest first.
  - All: upcoming first, then past.
  - A search or filter from the default page looks in All; after clicking a tab it stays inside that tab.
  - "Today" / "Tomorrow" label under the date.
- Super Admin appointment list: upcoming first (nearest on top), then past.
- No migration.
